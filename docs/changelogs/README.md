# Changelogs — архив текстов релизов

Здесь хранятся тексты **всех** опубликованных релизов SmartCon (stable и beta).
Имя файла = тег релиза: `v2.0.0.md`, `v2.0.1-beta.6.md`.

**Источник истины по оформлению:** skill `smartcon-changelog`
(`.agents/skills/smartcon-changelog/SKILL.md` → `references/templates.md`).

## Правила

1. Каждый новый релиз (stable или beta) **до публикации** получает файл в этой папке.
2. Файл передаётся в релиз-скрипт: `tools\release.ps1 -ChangelogFile docs\changelogs\v<версия>.md`.
3. После публикации файл не редактируется (это архив). Правки публикуемого текста — через `gh release edit`, затем файл синхронизируется с GitHub.
4. Стиль — пользовательский (benefit-first, русский язык, эмодзи-секции), НЕ список коммитов/файлов/тестов.
5. Stable-релиз формируется по ветке `main`, beta — по ветке `develop`.
