FamilyManager: Drag and Drop 2.0
Теперь можно перетаскивать семейство не только прямо на папку, но и на любой элемент внутри раскрытой категории. Drop автоматически попадает в родительскую категорию (поведение как в Explorer).
FamilyManager: Toolbar Redesign
Полностью переработан тулбар панели FamilyManager. Адаптивный layout с кнопками Import, Profile, Settings, Refresh. Кнопка Settings перенесена из футера в тулбар. Улучшены отступы, высоты элементов и выравнивание.
FamilyManager: Новые возможности
Поиск с debounce: 300ms задержка при вводе для предотвращения лишних перезагрузок дерева.
Сохранение состояния дерева: при активации поиска сохраняется раскрытое состояние категорий, при очистке поиска восстанавливается.
Снятие лимита загрузки: убрано ограничение в 500 элементов при загрузке каталога.
ComboBox с подтверждением: новое поведение для выпадающих списков, изменение требует подтверждения.
FamilyManager: Исправления
Исправлены layout проблемы toolbar (margins, heights, adaptive rows).
Исправлена утечка памяти в ComboBoxConfirmBehavior.
Исправлен захват CancellationToken в ProfileViewModel.
Исправлено окно подтверждения при загрузке ProfileView.
Технические улучшения
Обновлён инвариант I 14: DELETE journal mode для SQLite (совместимость с SMB).
Обратная совместимость DnD: ResolveParentDropTarget опциональное свойство, default false.
