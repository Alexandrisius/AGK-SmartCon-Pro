## 🔥 Главное в этом релизе

Главное — **автоматическое назначение категорий при импорте**: вы один раз описываете правила («если материал — сталь, то это фитинги»), и batch-импорт сам раскладывает семейства по каталогу. Плюс три точных фикса обновления семейств: перезапись параметров теперь затрагивает все типоразмеры, таблицы поиска участвуют в определении дубликатов, а ложные срабатывания проверки после обновления устранены.

**Топ-3 изменения для пользователя:**
1. **Автоназначение категорий по правилам** — batch-импорт раскладывает семейства сам, вам остаётся только подтвердить
2. **«Обновить с перезаписью параметров» чинит все типоразмеры** — раньше молча обновлялся только один
3. **Таблицы поиска (lookup) больше не путают версии** — правка CSV теперь корректно создаёт новую версию семейства

### FamilyManager

### 🎯 Автоназначение категорий при импорте (#241)
Задайте правила — и импорт перестанет требовать ручной разборки: подходящие семейства сами попадают в нужные категории.
- **Редактор правил** — в окне «Категории и атрибуты»: контекстное меню категории (или иконка фильтра на узле). Условия объединяются в группы: внутри группы — «И», между группами — «ИЛИ»
- **Условия по атрибутам** — параметр существует / есть значение / равно / содержит / больше / меньше / между
- **Условия по системным полям** — Категория Revit, Тип детали, Имя семейства
- **Умный импорт** — если правило даёт однозначный ответ, семейство сразу попадает в категорию; если подходят несколько — в колонке «Категория» появится ⚠ со списком кандидатов, выберите одним кликом
- **Иконки в дереве категорий** — видно, у каких категорий есть правила автоназначения
- **Правила путешествуют с пакетами** — экспорт/импорт метаданных переносит правила между базами (вместе с категориями и атрибутами)

### 🌳 Дерево каталога
- **Одна кнопка «развернуть/свернуть всё»** — вместо двух отдельных
- **Горизонтальная прокрутка Shift+колесо** — длинные имена категорий больше не требуют тянуть скроллбар

## 🐛 Исправленные ошибки

### Обновление семейств
- **«Обновить с перезаписью параметров» меняла значения только у одного типоразмера** (#239) — остальные типы оставались со старыми значениями. Теперь значения перезаписываются у всех загруженных типов
- **Правка таблицы поиска (lookup CSV) не создавала новую версию** (#238) — изменённая таблица не участвовала в расчёте хеша, и новая версия считалась дубликатом старой. Таблицы поиска теперь часть «отпечатка» семейства
- **Ложная ошибка проверки после обновления мульти-типовых семейств** (#240) — геометрия и коннекторы зависят от того, какой тип открыт в family-документе; проверка теперь сравнивает корректно и при сбое показывает диагностику, что именно разошлось

### Интерфейс
- **Случайное перетаскивание семейства при прокрутке дерева** (#236) — прокрутка за скроллбар запускала Drag-and-Drop, и семейство «уезжало» в другую категорию. Перетаскивание теперь стартует только с реального захвата элемента

### Диагностика
- **smartcon.log раздувался до десятков тысяч строк за сессию** (#237) — убран циклический спам записи геометрии и интерфейсных событий; лог снова читаемый

## 🧪 Как тестировать beta

### Автоназначение категорий (#241)
1. Откройте «Категории и атрибуты» → ПКМ на категории → «Правила автоназначения»
2. Добавьте группу и условие (например, «Имя семейства содержит „воздуховод"») → Сохранить
3. Запустите batch-импорт папки с такими семействами → **Ожидается:** строки сами получили категорию, мигнула подсветка ячейки
4. Задайте пересекающиеся правила для двух категорий → **Ожидается:** ⚠ в колонке «Категория», клик открывает пикер с кандидатами
5. Переименуйте строку с назначенной по правилу категорией → **Ожидается:** правило переоценилось, категория обновилась/снялась
6. Проверьте иконку правил на узле дерева категорий

### Обновление семейств (#239, #238, #240)
1. Семейство с 3+ типоразмерами → «Обновить с перезаписью параметров» → **Ожидается:** значения изменились у всех типов (проверьте таблицу типов)
2. Семейство с lookup-таблицей: замените CSV на изменённый → повторный импорт → **Ожидается:** создана новая версия, а не «дубликат»
3. Мульти-типовое семейство → обновление → **Ожидается:** проверка после обновления проходит без ложной ошибки

### Дерево (#236)
Прокручивайте дерево скроллбаром, зажав мышь над семейством → **Ожидается:** перетаскивание не запускается

### Логи
Пришлите `smartcon.log` после теста (путь: `%APPDATA%\AGK\SmartCon\smartcon.log`)
