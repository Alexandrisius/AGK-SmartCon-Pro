Это **крупнейшее обновление** в истории плагина. Перед установкой обязательно прочитайте данный раздел — он сэкономит вам время и убережёт от потери данных.
### 🚫 Несовместимость со старыми базами семейств
> **Каталоги семейств, созданные в SmartCon 1.9.3 и более ранних версиях, НЕ совместимы с SmartCon 2.0.0.**  
> При первом запуске 2.0.0 старый каталог не будет открыт — потребуется создать новый и импортировать семейства заново.
**Почему так сделано.** Модель хранения семейств переработана фундаментально:
- добавлена **дедупликация по содержимому** (цифровой отпечаток каждого `.rfa`);
- **каждая версия семейства теперь хранит собственный набор типов и атрибутов** (раньше — только последняя);
- добавлены таблицы для запоминания общих вложенных семейств;
- изменён путь к управляемым файлам и формат хранения версий.
**Что сохранить перед обновлением:**
1. Папку текущего каталога семейств (на случай отката на 1.9.3).
2. Список путей к исходным `.rfa`-файлам, которые были в каталоге.
3. Скриншоты дерева категорий (чтобы быстро воссоздать структуру).
### 📌 Другие важные изменения
- Команды **«Импорт папки»** и **«Импорт данных»** удалены — оставлен только пакетный импорт (он покрывает все сценарии).
- Кнопка **«Инкремент версии»** переименована в **«Новая версия»** (в русской и английской локали).
- Флаг **«Включить beta-обновления»** по умолчанию выключен. Включите его в настройках, если хотите получать будущие beta-релизы.
- Кнопка **«Импорт системного семейства»** переименована в **«Импорт выделенных элементов»** — теперь принимает любые элементы, не только системные.

## ✨ Новые возможности
### 🧊 3D-просмотр семейств
Вкладка **3D Просмотр** в окне свойств семейства больше не пустая.
- Интерактивный 3D-вьювер с вращением, зумом и панорамированием
- Геометрия извлекается автоматически при импорте и сохраняется для каждой версии
- Поддерживается во **всех версиях Revit** (2019–2025+)
- Для семейств с несколькими типами — выпадающий переключатель типов
- Корректное отображение **цветов материалов** для вложенных семейств
- **Плавный shading** для мелких деталей (например, 16-мм отводы — без видимых граней)
- **Камера сохраняется** при переключении между типами
- **Условные обозначения** (символика coarse-only) не попадают в 3D-превью
- Учитывается **видимость элементов**, настроенная для конкретного типа
- 3D-геометрия извлекается даже у семейств **без явных типоразмеров**
### 🗂️ Управление версиями семейств (вкладка «Версии»)
В окне свойств семейства появилась вкладка **Версии**.
- Просмотр всех сохранённых версий с датой, автором и количеством типов
- **Переключение активной версии одним кликом**
- Удаление неактивных версий
- Каждая версия хранит **собственный набор типов и атрибутов** независимо
- В диалоге импорта дубликата можно выбрать **«Сделать активной»** вместо создания новой версии
- Откат к старой версии восстанавливает **именно её** данные
### 🔎 Дедупликация семейств по содержимому
FamilyManager теперь автоматически находит одинаковые семейства, даже если они:
- переименованы;
- пересохранены через «Save As»;
- взяты из разных папок;
- получены из активного проекта.
В диалоге импорта появился новый статус **Дубликат** — такие строки автоматически пропускаются. При необходимости можно вручную выбрать **«Новая версия»**, если всё-таки нужна копия.
### 📦 Пакетный импорт семейств
Можно выбрать сразу **несколько `.rfa`-файлов** и загрузить их в каталог за один проход.
- В диалоге показывается таблица: имя файла, версия Revit, размер, статус, выбранное действие
- **Статусы для каждого файла:**
  - `Новое` — такого семейства в каталоге ещё нет
  - `Существующее` — семейство с таким именем есть, файл отличается по содержимому
  - `Дубликат` — файл с таким же содержимым уже в каталоге (автоматически «Пропустить»)
- **Действия (по каждой строке):**
  - **Новая версия** — создаётся следующая версия (`v2`, `v3` и т.д.), текущая переключается на новую
  - **Перезаписать текущую** — содержимое заменяется, номер версии сохраняется
  - **Пропустить** — файл не импортируется
- **Мульти-выбор строк** — можно выделить сразу несколько и применить действие или категорию батчем
- Перед открытием диалога проверяются права доступа (RBAC)
### 🖱️ Drag & Drop в проект
- Любое семейство из дерева каталога можно **перетащить** прямо в окно Revit — оно автоматически разместится там, где вы отпустили кнопку мыши
- При перетаскивании на **раскрытую категорию** — семейство кладётся в неё
- Результат отображается в статус-баре (успех, имя вложенного семейства, ошибка)
- Фокус окна Revit возвращается после размещения — больше не нужно кликать в Revit вручную
- Повторные перетаскивания работают быстрее за счёт кэша файлов
### 🟠 Индикатор устаревших семейств
В дереве каталога теперь видно, какие семейства в вашем проекте имеют **более старую версию**, чем та, что лежит в каталоге.
- При каждой загрузке семейства в проект плагин запоминает, **какая именно версия** была загружена
- При обновлении дерева (Refresh) версии сравниваются автоматически
- Если они различаются — рядом с названием появляется **оранжевый маркер** и подпись «Устарело»
- Отображается **имя текущей версии** (например, `v3`)
- Работает батчем — не тормозит UI даже на больших каталогах
### 🏗️ Поддержка системных семейств
Появился полноценный импорт **системных семейств** — тех, что встроены в Revit и не хранятся в отдельных `.rfa`:
- **Трубы**
- **Гибкие трубы**
- **Воздуховоды**
- **Гибкие воздуховоды**
- **Короба**
- **Лотки**
- **Стены**
Каждая категория имеет свой обработчик размещения — атрибуты корректно извлекаются через соответствующие методы Revit API.
**Команда «Импорт выделенных элементов»** — принимает **любые** элементы (системные и загружаемые). Новый фильтр выделяет как `FamilyInstance`, так и системные категории.
**Команда «Импорт активного файла»** — импортирует **и системные, и загружаемые** семейства из активного проекта:
- Сначала показывается **быстрый анализ** (менее секунды на 200 семейств) — без обращения к `.rfa`-файлам
- Пользователь видит сводку: «5 системных категорий (37 типов) и 87 загружаемых семейств» — и подтверждает
- Только после подтверждения плагин начинает открывать `.rfa` — никаких зависаний до клика
- В каталог попадают **только размещённые** семейства (не все загруженные в проект)
### 🧬 Type Catalog (каталог типоразмеров)
- Для каждого семейства извлекается и сохраняется **полный список типоразмеров**
- Универсальное определение кодировки `.txt` — корректно работает с кириллицей и разными региональными настройками
- Парсер соответствует международному стандарту CSV (RFC 4180) — корректные запятые в кавычках, экранирование, разные варианты переносов строк
- **Типоразмеры «запекаются» прямо в `.rfa` при импорте** (bake-in) — больше никаких `.txt`-сайдкаров рядом с файлом
- Корректная конвертация единиц измерения (`##TYPE##UNITS`) — больше никаких 215-футовых вентиляторов из миллиметров
- Поддержка семейств с **нулевым количеством типов**, **дубликатами** и **несовпадающими типами**
- Команда **«Перезаписать Type Catalog»** в подменю обновления семейства
### 🪟 Единый диалог загрузки общих вложенных семейств
Вложенные семейства теперь импортируются через **единое окно** вместо разрозненных окон для каждого случая.
- Один диалог покрывает все сценарии загрузки (из `.rfa`, из проекта, из каталога)
- Поведение консистентно между «Импорт активного файла», «Импорт выделенных», «Пакетный импорт»
- Решение официального бага Autodesk **REVIT-198137**: в Revit 2023/2024 имена вложенных семейств не возвращались — теперь берутся из локального каталога SmartCon
### 📂 Быстрый поиск в каталоге
- При вводе поискового запроса **категории автоматически раскрываются**
- **Подсветка совпадений** прямо в дереве
- Скрытие пустых категорий при поиске
- Восстановление состояния раскрытия после очистки поиска
- Кнопки **«Развернуть всё» / «Свернуть всё»** для каждой папки
- Глобальные **«Развернуть всё» / «Свернуть всё»** в панели инструментов
### 🔍 Кнопка «Найти в каталоге»
- Если в дереве Revit выделено какое-то семейство, кнопка подсвечивает его в каталоге FM
- Автоматическая прокрутка дерева к нужной категории
- Положение прокрутки и выделение сохраняются — удобно сверяться с тем, что уже используется в модели
### ✏️ Редактирование семейства в Family Editor
- Кнопка **«Редактировать»** в контекстном меню — открывает выбранное `.rfa` в Family Editor Revit, не покидая SmartCon
- Кнопка **«Загрузить активное семейство»** — если в Revit открыт `.rfa`, его можно сразу импортировать в каталог
- Исправлен импорт семейств, открытых в Family Editor (раньше терялись привязанные `.txt` Type Catalog)
### 🎨 Современный заголовок окна свойств семейства
- Обновлённый дизайн заголовка с **аватаром, тегами и статусом**
- Убраны избыточные поля (Manufacturer, Size)
- Соответствует современным UI-паттернам

## 🔧 Улучшения
### Импорт семейств
- **Быстрый импорт активного проекта** — файлы больше не открываются многократно. На тесте 42 семейств убраны десятки лишних открытий и сэкономлено около 12 секунд
- **Корректная перезапись текущей версии** — режим «Перезаписать текущую» работает для всех сценариев (импорт активного `.rfa`, импорт системных, импорт выделенных)
- **Сохранение набора загруженных типов при обновлении** — команда «Обновить» для устаревшего семейства больше не загружает в проект все типы из `.rfa`. Обновляются только те типы, которые уже были загружены
- **Импорт только размещённых семейств** — «Импорт активного файла» берёт только реально размещённые семейства, а не все загруженные в проект
- **Устранены «осиротевшие» временные папки** — loadable семейства сразу пишутся в постоянное хранилище
- **Синхронизация типов при повторном импорте** — удалённые в Revit типы больше не остаются в каталоге как «фантомные»
- **Устранено двойное расширение `.rfa.rfa`** при импорте семейства, открытого через команду Revit «Редактировать семейство»
- **Семейства не называются по имени `.rvt` файла** в смешанных проектах с системными и загружаемыми семействами
- **Корректное закрытие `.rfa` после импорта** — больше нет «Access Denied» при повторном открытии
### PipeConnect
- **Детерминированный выбор фитингов** — одна и та же операция «соедини два одинаковых вентиля» теперь всегда даёт одинаковый результат (раньше могла дать разный при повторных запусках)
- **Улучшенный матчинг типов** — используется полный код + имя + описание при определении типа
### Производительность и стабильность
- **Сканирование семейств в активном проекте** — в разы быстрее на больших проектах
- **Устранена утечка COM-объектов** при импорте 32+ файлов подряд (раньше приводило к memory corruption)
- **Структурированное логирование** — лог читается быстрее, корреляция операций работает надёжно
- **Уровень логирования зависит от конфигурации**: Debug — подробный, Release — лаконичный. Можно переопределить переменной среды
### Сборка и обновления
- **Мульти-версионная сборка** — SmartCon корректно собирается под все Revit (2019, 2021, 2024, 2025) без предупреждений
- **Обновление на Revit 2019–2024** — исправлена ошибка `WSAEACCES 10013` (нельзя переиспользовать порт после закрытия). Текст ошибки сокращён и локализован
- **Публикация на net48** — исправлена ошибка `NETSDK1152` (транзитивные зависимости не резолвились)
- **Обновления зависимостей** автоматизированы через Dependabot

## 🐛 Исправленные ошибки
### Стабильность
- **Зависание панели FamilyManager после импорта** — панель больше не «замирает» после операции сохранения извлечённого `.rfa` (критический фикс для Revit 2019–2024)
- **Белый диалог импорта на Revit 2019–2024** — после внутреннего апгрейда семейства диалог автоматически восстанавливает отрисовку
- **Пустое дерево при холодном старте в Revit 2023** — дерево каталога появляется сразу, без ручного Refresh
- **Пункт «Проверить» серый на 2+ ПКМ в Revit 2023** — больше не становится серым после первого нажатия правой кнопкой мыши
- **Категории дерева не раскрываются после поиска на Revit 2019–2024** — поиск работает корректно на всех поддерживаемых версиях Revit
### Импорт
- **«Импорт активного файла» предлагал все семейства проекта** — теперь только размещённые
- **Двойной показ диалога пакетного импорта** — теперь строго один раз
- **«Фантомные типы» в дереве** — пустые имена типов больше не появляются
- **Потеря Type Catalog при импорте активного семейства** — `.txt`-файл сохраняется
- **Дублирование категорий при импорте** — категория читается из авторитетного источника
- **Удалённые из Revit типы не синхронизировались с БД** — теперь синхронизируются
- **«Импорт активного файла» называл системное семейство по имени проекта** — теперь берётся настоящее имя категории
- **Доступ запрещён при повторном открытии `.rfa`** — корректное закрытие после импорта
### 3D-просмотр
- **Семейства без типов** — 3D-геометрия извлекается даже у семейств без явных типоразмеров
- **Условные обозначения** — coarse-only символика не попадает в 3D-превью
- **Цвета вложенных семейств** — материалы корректно извлекаются для всех вложенных элементов
- **Камера** — сохраняется при переключении между типами
- **Плавность мелких деталей** — 16-мм отводы отображаются гладко, без видимых граней
- **Видимость по типу** — скрытые в типе вложенные семейства не отображаются
### Каталог
- **Удаление категории** — курсор автоматически переходит на соседнюю категорию (раньше дерево оставалось без выделения)
- **Дерево сворачивается** при удалении последнего семейства из раскрытой категории — теперь сохраняет состояние раскрытия
- **Имя системного семейства** — в смешанных проектах системные семейства не называются по имени `.rvt` файла
- **Пробелы в конце имени файла** — `LoadFamily` больше не падает на именах вида `"filter .rfa"`
- **Фантомные типы** — пустые имена типов удалены из дерева, если в семействе нет явных типов
### PipeConnect
- **MiniTypeSelector** — корректно вызывается при невалидном Description у трубы в Revit 2023 (раньше не вызывался из-за несовпадения строк)

## 🔄 Как обновиться
### Автоматически
1. Запустите Revit — **SmartCon Updater** предложит обновиться до 2.0.0
2. Согласитесь и дождитесь перезапуска Revit
### Важно после обновления
1. **Создайте новый каталог семейств** — старый не совместим с 2.0.0
2. **Импортируйте семейства заново** через пакетный импорт или «Импорт активного файла»
3. **Структура категорий** воссоздаётся вручную (или импортируется из активного проекта)
4. **Включите beta-канал** в настройках, если хотите получать будущие beta-релизы (по умолчанию выключен)
5. **Переоткройте проекты**, в которых уже загружались семейства — индикатор устаревших семейств начнёт отображаться после первой загрузки
### Откат на 1.9.3
- Если 2.0.0 не подходит — откат на 1.9.3 через **SmartCon Updater** (Downgrade)
- Старый каталог семейств (если сохранили папку) снова работает с 1.9.3
