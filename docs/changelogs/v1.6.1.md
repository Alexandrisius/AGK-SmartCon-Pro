Share Project — управление разбором имён файлов и улучшения UX
Расширенный контроль над парсингом имён файлов в модуле Share Project, улучшения интерфейса настроек экспорта и рост тестового покрытия.
40 файлов изменено, +2 449 / −1 090 строк, 994 теста.
Ключевые возможности
1. Индексы вхождений для правил парсинга
Раньше все правила работали только с первым вхождением разделителя/маркера. Теперь пользователь выбирает, какое именно вхождение использовать — 2-й дефис, 3-я скобка и т.д.
- SegmentIndex (Разделитель) — какой по счёту сегмент взять (1 = первый)
- OpenMarkerIndex / CloseMarkerIndex (Между маркерами) — открывающий и закрывающий маркеры считаются от начала строки. CloseMarkerIndex всегда > OpenMarkerIndex
- MarkerIndex (После маркера) — какое вхождение маркера использовать
- CharOffset (Фиксированная ширина) — сколько символов пропустить от начала (0 = без пропуска)
Все индексы 1-based (пользователь вводит 1 для «первый»), CharOffset — 0-based (количество пропускаемых символов).
2. ParseRuleView — визуальный редактор правил
- Между маркерами разделён на две строки: открывающий и закрывающий маркеры — отдельно
- Новые поля ввода для всех индексов вхождений
- Живой предпросмотр результата при изменении любого параметра
- Окно увеличено до 480×410 для комфортной работы
3. FileNameBlockItem — информативные подписи
Блоки в цепочке парсинга показывают индекс, когда он отличается от значения по умолчанию:
- Разделитель [_] №2 — второй сегмент по разделителю _
- ( ... ) (открывающий №2, закрывающий №3) — конкретные вхождения маркеров
- После [-] №2 — второе вхождение маркера
4. Share Settings — вкладка «Виды»
- Добавлена подсказка «Виды для сохранения в Shared-файле:» — пользователь понимает, что выбирает виды для сохранения, а не удаления
- Поиск по видам получил placeholder «Поиск вида...» — серый текст-подсказка, исчезает при вводе
5. Share Settings — вкладка «Очистка»
- Группы: подпись изменена с «Группы и типы групп» на «Группы (разгруппировать)» — пользователь понимает, что группы не удаляются, а разгруппировываются
- Сборки: подпись изменена с «Сборки» на «Сборки (разобрать)» — сборки разбираются на составляющие, а не удаляются
