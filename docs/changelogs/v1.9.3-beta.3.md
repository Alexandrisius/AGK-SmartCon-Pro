Bug Fixes
- 
#57 — Drag&Drop без проверки прав  
Пользователи с ролью "Engineer" больше не могут перетаскивать семейства в дереве категорий. Добавлена проверка CanEdit в CanStartDrag, CanDropFamily и MoveFamilyToCategoryAsync.
- 
#58 — Удаление семейства без удаления файлов  
WPF Image control больше не блокирует preview-файлы при просмотре свойств семейства (новый PathToBitmapImageConverter с CacheOption=OnLoad + Freeze()).  
Изменён порядок удаления: сначала файлы, потом запись из БД (fail-fast). Если файлы заняты — семейство остаётся в каталоге. Retry увеличен до 5 с GC.Collect() перед финальной попыткой.
- 
WPF dockable panel freeze после диалога обновления семейства  
Исправлено зависание панели Family Manager при импорте/обновлении. Root cause: FireAndForget(async) + PropertyChanged до ExternalEvent.Raise() вызывали zombie-состояние WPF render thread при MFC-диалоге. Переписано на синхронный паттерн ExternalEvent.Raise().
- 
Family Manager services — ConfigureAwait(false)  
Добавлен ConfigureAwait(false) во всех async-методах сервисов локального каталога для предотвращения deadlock при синхронных ожиданиях.
