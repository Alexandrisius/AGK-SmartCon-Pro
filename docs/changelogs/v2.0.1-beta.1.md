## 🔥 Главное в этом релизе

Этот beta-релиз продолжает развитие модуля **FamilyManager**. В центре внимания — крупная функция **проектных баз семейств**, которая автоматически переключает библиотеку в зависимости от открытого Revit-проекта. Помимо этого, внесены десятки улучшений UI и стабильности, накопленных после релиза 2.0.0.

**Топ-5 изменений для пользователя:**

1. **Проектные базы семейств** — база теперь может автоматически активироваться под конкретный Revit-проект
2. **Переработанная вкладка «Содержимое»** — двухпанельный интерфейс с категориями и превью файлов
3. **Переработанная вкладка «Атрибуты»** — удобная группировка по группам атрибутов
4. **Улучшенный Drag & Drop** — плавный автоматический скролл при перетаскивании семейств
5. **Надёжное удаление баз** — базы с защищёнными `.rfa` файлами теперь удаляются корректно

## ✨ Новые возможности

### 🏗️ Проектные базы семейств

FamilyManager теперь поддерживает два типа баз:

- **Общие базы** — доступны для любого Revit-проекта, как раньше
- **Проектные базы** — привязываются к имени файла Revit-проекта по настраиваемому шаблону и автоматически активируются при открытии подходящего проекта

**Зачем это нужно.** Если вы ведёте несколько проектов одновременно, SmartCon теперь сам подберёт нужную библиотеку семейств под текущий открытый проект. Это исключает случайную загрузку семейств из чужого проекта.

**Как это работает:**

- При создании базы можно выбрать «Проектная база»
- В редакторе правил задаётся шаблон привязки к имени файла (например, по коду проекта в названии `.rvt`)
- При смене активного документа в Revit SmartCon проверяет имя файла и автоматически активирует подходящую проектную базу
- Если текущий проект не подходит к активной проектной базе, команды «Загрузить в проект» и «Разместить тип» блокируются. Пиктограмма замка в интерфейсе подскажет, почему действие недоступно

**Новый интерфейс баз:**

- Кнопка «+» теперь открывает меню выбора типа базы (общая / проектная)
- Справа от выпадающего списка баз добавлена единая кнопка управления: подключить существующую, отвязать, настроить правила проектной базы, удалить
- В списке баз отображаются иконки: общая база, подходящая проектная база, несовместимая проектная база

## 🔧 Улучшения

### Вкладка «Содержимое» семейства

Полностью переработан интерфейс:

- Левая панель со списком категорий (Все, Изображения, Видео, Документы, Таблицы, Прочее) и счётчиками файлов
- Правая панель — содержимое выбранной категории
- Миниатюры для изображений
- Единая кнопка «Добавить файл» с автоматическим определением категории по расширению
- Переключатель «Привязать к версии» для каждого файла
- Иконка «звезда» вместо текстовой кнопки «Сделать основным»
- Автоматически извлечённые GLB-файлы больше не попадают в общий список содержимого — они остаются на вкладке **3D Просмотр**

### Вкладка «Атрибуты» семейства

- Двухпанельный макет: слева список групп атрибутов, справа — значения атрибутов выбранной группы
- Длинные значения атрибутов теперь переносятся и не обрезаются без индикации; полное значение показывается во всплывающей подсказке

### Заголовок окна свойств семейства

- Поля «Статус» и «Теги» теперь расположены в одном стиле с «Именем» и «Категорией» — подпись над полем ввода
- Убрана визуальная неоднородность между верхними полями карточки

### Дерево категорий

- **Закреплённые заголовки категорий** при скролле теперь отображают только один путь от корня к текущей категории. Раньше в строку могли попадать соседние категории и менять порядок
- **Drag & Drop** — при перетаскивании семейства к краю дерева автоматический скролл стал плавным и плавным; больше не зависит от того, попадает ли курсор в зону цели
- **Длинные имена семейств** — при клике на семейство с длинным именем дерево больше не прокручивается горизонтально, скрывая левую часть

### Подсказка в колонке «Типы»

- Тултип с перечнем типоразмеров теперь показывает вертикальный маркированный список со скроллом вместо одной длинной строки

### 3D Просмотр

- Если у семейства отсутствует заранее извлечённый GLB, плагин пытается построить превью на лету из управляемого `.rfa`
- Расширено релизное логирование pipeline 3D-геометрии для упрощения диагностики

### Сборка и стабильность

- Окна «Настройки» и «О программе» в PipeConnect теперь открываются через единый диалоговый презентер, что повышает стабильность в Revit 2019–2024
- Устранён неиспользуемый код внешних событий PipeConnect

## 🐛 Исправленные ошибки

### FamilyManager

- **Удаление базы с read-only `.rfa` файлами** раньше завершалось ошибкой. Теперь файлы корректно освобождаются, удаляются или, если файл занят Revit, перемещаются в корзину для очистки при следующем запуске
- **Иконка папки** в выпадающем списке баз для подходящей проектной базы теперь отображается в приглушённом цвете, как и остальные второстепенные элементы
- **Дерево не «убегает» вправо** при выборе семейства с длинным именем — горизонтальный скролл остаётся на месте

### Зависимости

- Откат обновления `System.Text.Encoding.CodePages` до версии 8.0.0 — версия 10.x приводила к невозможности загрузки SmartCon в Revit

## 🧪 Как тестировать beta

### Проектные базы

1. Создайте новую «Проектную базу» и настройте правило привязки к имени файла
2. Откройте подходящий `.rvt` — база должна активироваться автоматически
3. Откройте другой проект — активируется первая общая база, или текущая проектная база отобразится с замком
4. Попробуйте загрузить семейство из несовместимой проектной базы — команда должна быть заблокирована

### UI FamilyManager

1. Откройте свойства семейства с файлами и проверьте вкладку «Содержимое» — категории, миниатюры, переключатель версии
2. Откройте вкладку «Атрибуты» — проверьте группировку и отображение длинных значений
3. Проверьте, что при клике на длинное имя семейства дерево не прокручивается горизонтально
4. Попробуйте перетащить семейство в проект — убедитесь, что автоматический скролл работает плавно

### Общее

1. Удалите базу, в которую ранее импортировали `.rfa` — папка должна исчезнуть без ошибки
2. Пришлите `smartcon.log` после теста (путь: `%APPDATA%\AGK\SmartCon\smartcon.log`)
