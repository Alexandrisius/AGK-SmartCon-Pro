🐛 FamilyManager: Исправлен баг #54 — загрузка семейств с пробелом перед .rfa

Проблема: Файлы вида `Имя .rfa` (с пробелом перед расширением) не загружались в Revit. Revit API выполнял три попытки, после чего создавал в проекте семейство с мусорным GUID-именем (`SmartCon_Family_a67589...`), которое отображалось в диспетчере проекта.

**Исправление:**
- Убран fallback с загрузкой из Temp\ — больше не создаются GUID-имена в проекте
- Все имена файлов теперь нормализуются (`Trim()`) при импорте, загрузке и переименовании
- Добавлены понятные сообщения об ошибках в статусной строке:
  - `"В имени файла есть пробел перед расширением. Переименуйте файл и импортируйте заново."`
  - `"Слишком длинный путь к файлу. Переместите файл в папку с более коротким путём."`

✨ FamilyManager: Оптимизация загрузки — проверка VersionGuid

**Что нового:**
- При загрузке семейства проверяется VersionGuid — если файл не изменился, загрузка пропускается со статусом `"Уже актуальная версия"`
- Разделены команды **Загрузить в проект** и **Разместить**:
  - LoadToProject — только загружает семейство
  - Place — только размещает (кнопка активна только после успешной загрузки)
- Добавлен enum `FamilyLoadStatus`: Loaded, Updated, Current, Failed
