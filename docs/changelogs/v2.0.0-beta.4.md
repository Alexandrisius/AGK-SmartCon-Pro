## Что нового
### 1. Дедупликация семейств по содержимому (Content-hash)
FamilyManager теперь умеет находить одинаковые семейства даже если они:
- переименованы;
- пересохранены через Save As;
- взяты из разных папок;
- получены из активного проекта.
В диалоге импорта появился новый статус **Дубликат**. Такие строки автоматически пропускаются, но вы можете вручную выбрать **Новая версия**, если всё-таки нужна копия.
### 2. Управление версиями — вкладка «Версии»
В окне свойств семейства появилась вкладка **Версии**:
- просмотр всех сохранённых версий с датой, автором и количеством типов;
- переключение активной версии одним кликом;
- удаление неактивных версий;
- в диалоге импорта дубликата можно выбрать **Сделать активной** вместо создания новой версии.
Теперь каждая версия хранит свой набор типов и атрибутов независимо — откат на старую версию восстанавливает именно её данные.
### 3. 3D-просмотр семейств
Вкладка **3D Просмотр** в окне свойств семейства больше не пустая:
- интерактивный 3D-вьювер с вращением, зумом и панорамированием;
- геометрия извлекается автоматически при импорте и сохраняется для каждой версии;
- для семейств с несколькими типами есть выпадающий переключатель типов;
- поддерживается Revit 2025+ и Revit 2019–2024.
### 4. Быстрый импорт активного проекта
Импорт семейств из активного проекта ускорен: файлы больше не открываются многократно. В тесте на 42 семействах убраны десятки лишних открытий и сэкономлено около 12 секунд.
### 5. Корректная перезапись текущей версии
Режим **Перезаписать текущую версию** в диалоге импорта теперь работает для всех сценариев:
- импорт активного `.rfa`;
- импорт системных семейств из активного проекта;
- импорт выделенных элементов.
Версия не инкрементируется — обновляется содержимое текущей.
### 6. Обновление устаревших семейств сохраняет загруженные типы
Команда **Обновить** для устаревшего семейства больше не загружает в проект все типы из `.rfa`. Теперь обновляются только те типы, которые уже были загружены в проект.

## Исправления
- **Поиск в каталоге** — категории теперь автоматически раскрываются при вводе поискового запроса и корректно восстанавливают состояние после очистки.
- **Двойное расширение `.rfa`** — устранено появление `.rfa.rfa` в имени файла при импорте семейства, открытого через встроенную команду Revit **Редактировать семейство**.
- **Качество 3D-моделей** — мелкие детали (например, 16-мм отводы) теперь отображаются гладко, без видимых граней.
- **Семейства без типов** — теперь извлекается и показывается 3D-геометрия даже у семейств без явных типоразмеров.
- **Условные обозначения** — coarse-only символика больше не попадает в 3D-превью.
---
## Стабильность
- **Белый диалог импорта на Revit 2019–2024** — добавлен workaround: после внутреннего апгрейда семейства диалог автоматически восстанавливает отрисовку.
- **Зависание панели FamilyManager** — после импорта панель автоматически «подталкивается» всплывающим уведомлением, чтобы не зависала.
