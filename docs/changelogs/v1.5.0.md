Новая функция: Share Project (Экспорт проекта)
Модуль для экспорта Revit-проектов в Shared-папку по стандарту ISO 19650. Два новых кнопки на ленте: Export Project (экспорт) и Settings (настройки).
Алгоритм экспорта (8 шагов):
- Синхронизация с центральным файлом
- Создание временного проекта и переключение
- Открепление от центрального файла (Detach & Preserve)
- Очистка модели (листы, виды, CAD-импорты, Revit-ссылки, группы и т.д.)
- Сохранение в Shared-папку с новым именем
- Возврат к оригинальному файлу
Движок именования v2:
- Настраиваемый шаблон имени из блоков (поле + правило парсинга)
- 5 режимов парсинга: по разделителю, фиксированная ширина, между маркерами, после маркера, остаток
- Библиотека полей с валидацией: из списка допустимых значений / по длине текста
- Маппинг экспорта — подмена значений полей при экспорте (напр. WIP → SHARED)
- Живая валидация текущего и будущего имени файла с визуальной индикацией
- Кнопки ▲ ▼ для перестановки блоков с пересчётом парсинга
- Импорт/экспорт настроек в JSON для переноса между проектами
Настройки экспорта:
- Путь к Shared-папке
- 12 категорий очистки модели (с возможностью исключения конкретных видов)
- Синхронизация перед экспортом (опционально)
Совместимость:
- Revit 2019–2026 (net48 + net8.0-windows)
- Критические исправления для net48: диалоги, прогресс-бар, Dispatcher
