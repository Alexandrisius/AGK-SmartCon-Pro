Типоразмеры в выпадающем списке DN (ADR-011)
При наличии нескольких типоразмеров с одинаковым DN (например, «Отвод», «Исполнение 2», «Исполнение 2 — 108»), в выпадающем списке теперь отображается имя типоразмера в скобках: DN 50 (Отвод), DN 50 (Исполнение 2). Пользователь видит точную конфигурацию, которую выбирает.
- Кросс-табличный маппинг: типоразмер определяется по всем lookup-таблицам семейства, а не только по «лучшей»
- Orphan-детекция: типоразмеры, не соответствующие ни одной строке CSV, исключаются из списка (невозможно выбрать сломанную конфигурацию)
- Multi-mapping: одна CSV-строка может соответствовать нескольким типоразмерам с одинаковыми параметрами
Типоразмер в строке АВТОПОДБОР
Автоподбор теперь показывает текущий типоразмер элемента: АВТОПОДБОР (DN 50) (Исполнение 2). Раньше вместо текущего отображался ближайший по DN, который мог быть другим типом.
Безопасное переключение коннекторов (Cycle Connector)
Переключение на следующий коннектор в S6 теперь работает безопасно:
- Проверка CTC перед продолжением — если тип соединения не определён, открывается MiniTypeSelector
- Выравнивание выполняется до MiniTypeSelector (пользователь видит ориентацию)
- Откат выравнивания при отмене выбора типа
- Пересчёт фитингов, размеров и редьюсеров после переключения
- Защита цепочки: откат уровней цепочки при отмене
Исправлено
- Редьюсеры при непрямом соединении: редьюсеры теперь доступны для выбора при любом типе соединения (прямое/непрямое). Раньше они принудительно очищались при снятии галочки «Прямое»
- Единицы измерения в lookup-таблицах: значения параметров и CSV-ячеек нормализуются в канонические единицы (мм/градусы). Исправлен баг, при котором параметр LENGTH в футах (0.003281) не совпадал со значением в CSV (1.0 мм) → маппинг типоразмеров полностью ломался
- Лог-спам: убран избыточный вывод LookupSection в lookup-diagnostic.log
Инфраструктура
- build-and-deploy.bat: единый скрипт сборки всех версий Revit (2019/2021-2023/2025) через именованные конфигурации Debug.R25/.R23/.R19. Старый способ через -p:RevitVersion=... ломал restore пакета RevitAPI
- RevitUnitsCompat: кросс-версионный helper конверсии единиц (Revit 2019-2025)
- SizeRowSymbolMatcher: pure-C# логика маппинга CSV-строк на типоразмеры (покрыта unit-тестами)
