FamilyManager — новый модуль управления библиотекой семейств Revit
Полноценная dockable-панель для каталогизации, поиска и загрузки семейств (.rfa) прямо из интерфейса Revit. Построена на SQLite с поддержкой Published Storage по стандарту ISO 19650.
220 файлов изменено, +35 900 строк кода, 936 тестов.
---
Ключевые возможности
- Dockable Panel — каталог семейств всегда под рукой, не перекрывает рабочее пространство
- SQLite-каталог — быстрый поиск, фильтрация по статусу/категории/тегам, сортировка
- Иерархия категорий — древовидная структура с drag-and-drop для реорганизации, визуальный редактор дерева
- Импорт семейств — drag-and-drop .rfa на панель, импорт одного файла или целой папки, автоматическое определение версии Revit через BasicFileInfo
- Published Storage (ISO 19650) — статусы Active / Deprecated / Retired для управления жизненным циклом контента (ADR-015)
- Multi-Database — создание, подключение, переключение и удаление нескольких баз данных (корпоративный каталог, личный, проектный)
- Asset Management — привязка вспомогательных файлов (изображения, документы, таблицы) к семействам
- Attribute Presets — настраиваемые пресеты извлечения параметров для каждой категории
- Типоразмеры — извлечение, кэширование и размещение типоразмеров семейств
- Load & Place — загрузка семейства в проект и мгновенное размещение экземпляра
- Обновление семейств — реимпорт с автоматическим инкрементом версии
- Read-only managed storage — защита файлов от случайного изменения (ADR-016)
