## 🚀 Новые возможности
### 1. Role-Based Access Control (RBAC) для FamilyManager (#45)
Реализована полноценная система разграничения прав доступа к каталогу семейств с тремя уровнями ролей:
| Роль | Права |
|------|-------|
| **Owner** | Полный контроль: импорт, редактирование, удаление, управление пользователями и передача прав собственности |
| **BimMaster** | Импорт семейств, редактирование параметров, управление категориями |
| **Engineer** | Только чтение каталога + загрузка/размещение семейств в проекте |
**Ключевые компоненты:**
- **Управление пользователями:** диалог `ProfileView` доступен Owner'у для добавления, блокировки и назначения ролей.
- **Автоматическое распознавание:** пользователь идентифицируется по Windows-логину + имени машины.
- **Проверка прав в реальном времени:** все команды (`Import`, `Edit`, `Delete`) имеют `CanExecute`-валидацию.
- **Миграция БД:** автоматическое обновление схемы до v7 с таблицей `db_users` и колонкой `owner_identity`.
### 2. Улучшенный Drag-and-Drop (#44)
- **Drop на раскрытую категорию:** при перетаскивании семейства на дочерний элемент внутри раскрытой категории цель автоматически резолвится в родительскую категорию.
- **Визуальная обратная связь (adorner)** работает на resolved target.
- Активировано в `FamilyManager` по умолчанию.
### 3. Редизайн панели FamilyManager
- **Адаптивный тулбар:** двухстрочный макет с группировкой кнопок (`Import` + `Profile`, `Search`).
- **Кнопки Refresh и Clear Search:** быстрый сброс дерева и очистка поиска.
- **ComboBox с подтверждением:** поведение `ComboBoxConfirmBehavior` с подтверждением изменения роли пользователя.

## 🏗️ Архитектурные изменения (для разработчиков)
### Критический рефакторинг: удаление Revit API из FamilyManager
Соблюдён инвариант **I-09**: `SmartCon.Core` и `SmartCon.FamilyManager` не содержат вызовов Revit API.  
Созданы 4 новых сервиса:
| Интерфейс (Core) | Реализация (Revit) |
|------------------|--------------------|
| `IFamilySearchService` | `RevitFamilySearchService` |
| `IFamilyPlacementService` | `RevitFamilyPlacementService` |
| `IFamilyTypeExtractor` | `RevitFamilyTypeExtractor` |
| `IFamilyLoadOptionsFactory` | `RevitFamilyLoadOptionsFactory` |
**Удалено из FamilyManager:**
- `using Autodesk.Revit.DB` и `using Autodesk.Revit.UI` из `LoadPlace.cs`.
- `TaskDialog.Show` → заменён на WPF `MessageBox`.
- Прямые вызовы `doc.Application.Username` → кэширование через `IRevitContext.GetUsername()`.
### Thread Safety & ExternalEvent
- **ExternalEvent Queue:** заменён `Interlocked.Exchange` на `ConcurrentQueue<Action<<UIApplication>>` — обработка всех накопленных действий за один вызов `Execute()` (best practice Autodesk).
- **`Task.Run()` в колбэках:** SQLite-операции внутри `ExternalEvent` обёрнуты в `Task.Run()` для предотвращения deadlock.
- **`CancellationTokenSource`:** паттерн `Interlocked.Exchange` для атомарной смены CTS + `Dispose()` для предотвращения утечек при быстром вводе в поиске.
### Новые модели и интерфейсы (Core)
**Модели:**
- `DbUser`, `DbUserRole`, `DbUserStatus`, `UserIdentity`
- `DbAccessDeniedException` (с поддержкой сериализации)
**Интерфейсы:**
- `IUserIdentityService`, `IDbUserRepository`, `IDbAccessControlService`
- `IWindowFocusService`
