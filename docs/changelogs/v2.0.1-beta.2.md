# SmartCon v2.0.1-beta.2
**Дата релиза:** 15 июля 2026  
**Предыдущий релиз:** 2.0.1-beta.1 (10 июля 2026)  
**Платформы:** Revit 2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026  
**Статус:** Pre-release (beta) — предназначена для тестирования
---
## 🔥 Главное в этом релизе
Этот beta-релиз продолжает стабилизацию модуля **FamilyManager** после введения проектных баз. Ключевое изменение — полный отказ от сторонней библиотеки **SharpGLTF.Core** в пользу собственного GLB- writer для 3D-просмотра, что устраняет совместимые проблемы с Revit 2021 и исправляет ориентацию моделей. Также добавлены всплывающие подсказки в дереве семейств и новый режим валидации полей.
**Топ-5 изменений для пользователя:**
1. **Собственный GLB writer** — устраняет краш `System.Text.Json` в Revit 2021 и переворачивает модели в правильную ориентацию
2. **Автоактивация проектной базы** — база теперь активируется при Save/SaveAs проекта без переключения вкладок
3. **Подсказки в дереве семейств** — тултип с аватаром и описанием при наведении на семейство
4. **Режим валидации Contains** — новый способ проверки поля по вхождению подстроки
5. **Стабильность 3D-просмотра** — больше не запускается извлечение геометрии при смене основного изображения

## ✨ Новые возможности
### 🏷️ Подсказки с аватаром и описанием в дереве семейств
FamilyManager теперь показывает всплывающую подсказку при наведении на семейство в дереве категорий:
- **Аватар семейства** — загружается лениво через `IFamilyAssetService`
- **Описание семейства** — отображается под изображением
- Состояния «нет изображения», «нет описания» и «загрузка» локализованы
- Подсказка реализована как отдельный `UserControl` с фиксированным размером 240×180
### 🔎 Режим валидации Contains
В `ProjectManagement` и `FamilyManager` добавлен новый режим проверки полей:
- **ValidationMode.Contains** — проверяет вхождение одной из заданных подстрок в значение поля (логика ИЛИ)
- Значения и подстроки нормализуются через `Trim()`
- Аналогичная нормализация применена к `AllowedValues` и `CharCount`
### 📝 Редактор AllowedValues
Переработан интерфейс редактора разрешённых значений:
- Таблица стала inline-редактируемой: двойной клик — и строка сразу в режиме редактирования
- Команды **Добавить**, **Удалить**, **Вверх**, **Вниз** для управления списком
- Автофокус на новой строке через `DataGridEditNewRowBehavior` в `SmartCon.UI`
- Заголовок диалога переименован в «Редактор валидации поля»
- Колонка валидации в `FieldLibraryView` расширена для длинных названий режимов

## 🔧 Улучшения
### 3D Просмотр
- **Собственный GLB writer** — полностью заменён `SharpGLTF.Core` на чистый C# writer с `StringBuilder`-JSON и ручной бинарной обёрткой GLB 2.0
- **Ориентация моделей** — матрица трансформации транспонируется из row-major (.NET) в column-major (glTF), поэтому Revit Z-up корректно отображается как glTF Y-up (модели больше не вверх ногами)
- **Совместимость с Revit 2021** — устранена `MissingMethodException` из-за конфликта версий `System.Text.Json`
- **glTF 2.0 alignment** — 4-байтовое выравнивание между мешами после нечётных `UNSIGNED_SHORT` индексных буферов и корректный `chunkLength` с учётом padding
- **Улучшенное pipeline-логирование** — удалены `.GetAwaiter().GetResult()` и прямой `Stopwatch` в пользу асинхронных паттернов и `SmartConLogger.Measure`
### Проектные базы
- **Автоактивация при Save/SaveAs** — `ActiveDocumentChangeNotifier` теперь слушает события `ControlledApplication.DocumentSaved` и `DocumentSavedAs`, и при сохранении активного проектного документа с новым путём автоматически пересчитывает подходящую проектную базу без необходимости переключать вкладки
- Добавлены `ActiveDocumentPathChangedEventArgs` и `ActiveDocumentPathChangeReason` в интерфейс `IActiveDocumentChangeNotifier`
- Фильтрация: только успешные сохранения, не семейства, не пустой `PathName`, активный документ и изменившийся путь
### Дерево категорий
- **Длинные имена семейств** — при выборе семейства с длинным именем дерево больше не прокручивается горизонтально, скрывая левую часть. Добавлено attached behavior `TreeViewBehaviors.SuppressHorizontalScrollOnBringIntoView` в `FamilyTreeItemBaseStyle`
### Удаление базы
- **Надёжное удаление read-only `.rfa`** — `DatabaseManager` теперь очищает пул подключений SQLite, сбрасывает атрибут read-only рекурсивно, повторяет попытку удаления и, если папка занята Revit, перемещает её в `%APPDATA%\AGK\SmartCon\FamilyManager\.trash` для очистки при следующем запуске

## 🐛 Исправленные ошибки
### FamilyManager
- **3D-экстракция запускалась при смене основного изображения** — убран побочный эффект из сеттера `Selected3DTypeName`; загрузка превью теперь вызывается только явно из `ChangeSelected3DTypeCommand` или обработчика `Loaded` вьюпорта. `LoadAssetsAsync` больше не инициирует извлечение 3D-геометрии
- **ComboBox сбрасывал выбор 3D-типа** — implicit `TwoWay SelectedItem` заменён на `OneWay` + explicit `SelectionChanged` command, чтобы обновление `ItemsSource` не записывало `null` обратно
- **Fallback-извлечение `.rfa` по требованию** — методы `Load3DPreviewForTypeAsync` и `TryExtract3DPreviewOnDemandAsync` теперь защищены от `null`/пустого `typeName`
- **Инициализация 3D-вьюпорта** — `Initialize3DInfrastructure` откладывается до тех пор, пока `ActualWidth`/`ActualHeight` > 0
- **Сохранение выбора 3D-типа** — предыдущий выбор 3D-типа сохраняется при перезагрузке ассетов в `Populate3DTypeNames`
### Сборка и зависимости
- **Revit 2021** — устранён краш `System.Text.Json` путём удаления зависимости `SharpGLTF.Core`
- **GLB соответствие спецификации** — исправлено 4-байтовое выравнивание и учёт padding в `chunkLength`

## 🧪 Как тестировать beta
### 3D Просмотр
1. Откройте FamilyManager в **Revit 2021** и выберите семейство без заранее извлечённого GLB
2. Переключитесь на вкладку **3D Просмотр** — модель должна загрузиться без краша
3. Проверьте, что модель ориентирована правильно (не вверх ногами)
4. Повторите в Revit 2024 и 2025
### Проектные базы
1. Создайте проектную базу с правилом привязки к имени файла
2. Откройте подходящий `.rvt`, сделайте **Save As** под новым именем
3. Убедитесь, что SmartCon автоматически пересчитал активную базу без переключения вкладок
### Подсказки в дереве
1. Наведите курсор на семейство в дереве категорий
2. Подождите — должна появиться подсказка с изображением и описанием
3. Проверьте семейства без изображения и без описания — должны быть корректные fallback-строки
### Валидация Contains
1. Откройте библиотеку полей в ProjectManagement или FamilyManager
2. Добавьте/отредактируйте поле с режимом **Contains**
3. Задайте несколько подстрок, сохраните
4. Проверьте, что значение проходит валидацию, если содержит хотя бы одну из подстрок
### Редактор AllowedValues
1. Откройте редактор валидации для поля с режимом AllowedValues
2. Добавьте новую строку — курсор должен сразу перейти в режим редактирования
3. Проверьте кнопки Вверх/Вниз и Удалить
### Общее
1. Удалите базу, в которую ранее импортировали `.rfa` — папка должна исчезнуть без ошибки, либо переместиться в `.trash`
2. Пришлите `smartcon.log` после теста (путь: `%APPDATA%\AGK\SmartCon\smartcon.log`)
