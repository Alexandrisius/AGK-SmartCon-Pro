v1.3.0 — Настраиваемое хранилище данных для маппинга фитингов

Новое

* Маппинг фитингов теперь хранится в самом проекте Revit (.rvt), а не в глобальном файле %APPDATA%\\AGK\\SmartCon\\connector-mapping.json. Настройки переносятся вместе с моделью: при передаче файла коллеге правила переноса типов, список типов коннекторов и таблицы переходов передаются автоматически.
* Кнопки «Импорт JSON» и «Экспорт JSON» добавлены в окно настроек маппинга (на вкладках «Типы» и «Правила»), что позволяет вручную переносить маппинг между проектами или создавать резервные копии.
* Диалог импорта по умолчанию открывается в %APPDATA%\\AGK\\SmartCon\\, если там сохранился старый файл connector-mapping.json, что удобно для первичного переноса настроек из предыдущей версии.
* Окно настроек стало модальным — корректно привязано к главному окну Revit и не теряется за другими окнами.

Исправления

* Ошибка сохранения маппинга «Writing of Entities of this Schema is not allowed to the current add-in» устранена (корректно настроены уровни доступа ExtensibleStorage).
* Кнопки Импорт/Экспорт размещены на одной линии с остальными кнопками (Добавить/Удалить/Сохранить), что предотвращает растяжение окна в высоту.

Миграция с предыдущей версии

* Автоматический импорт из старого файла connector-mapping.json не выполняется, что защищает от скрытого импорта устаревших правил в новый проект.
* Для переноса настроек откройте Настройки → Импорт JSON, и диалог предложит файл из AppData.
* Старый файл connector-mapping.json можно сохранить как резервную копию; плагин его больше не использует.
