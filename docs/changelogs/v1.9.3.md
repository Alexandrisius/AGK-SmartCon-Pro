## Основные изменения
- **Критически важные исправления для обеспечения стабильности** — устранены зависания потока рендеринга WPF при работе с диалоговыми окнами MFC (обновление семейства, OpenDocumentFile)
- **Устойчивость FamilyManager** — устранены сбои при отсутствии подключения к базе данных, при удалении файлов с атрибутами «только для чтения», а также при изменении разрешений на перетаскивание
- **Умная загрузка семейства** — обнаружение обновлений на основе VersionGuid предотвращает ненужные перезагрузки; исправлена ошибка с пробелами в конце
- **Полное извлечение параметров** — теперь извлекаются все параметры семейства (общие и системные) с отображением по категориям
- **Корпоративные диалоги** — новый шаблон подтверждения закрытия для несохраненных изменений во всех диалогах

## Исправление ошибок
### Стабильность и зависания
- **Зависание потока рендеринга WPF** — исправлено состояние «зомби», возникавшее при срабатывании `PropertyChanged` до `ExternalEvent.Raise()` в диалогах MFC (#54, #58)
- **Зависание панели Dockable** — удалена блокировка ведения журнала в обратных вызовах ExternalEvent; рефакторинг ImportData в шаблон синхронного вызова
- **UpdateFamily Freeze** — все обновления `StatusMessage` перенесены в обработчик ExternalEvent перед вызовом `OpenDocumentFile`
- **SmartConLogger.Freeze Deadlock** — вместо `Freeze` (синхронизация ввода-вывода) перед вызовами `LoadFamily` используется `Info` (буферизация)
### Сбои в работе FamilyManager
- **Сбой при нажатии на кнопку профиля** — `OpenProfileCommand` больше не приводит к сбою при отсутствии подключения к базе данных (связано с #54)
- **Пустая строка состояния** — вместо пустой строки отображается сообщение «База данных не подключена»
- **Дерево не отображается** — исправлен порядок вызова в методах `ConnectDatabaseAsync` / `CreateDatabaseAsync` / `SwitchDatabaseAsync`
- **Ошибка при удалении семейства** — исправлено сообщение «Доступ запрещен» для файлов, доступных только для чтения; добавлена рекурсивная очистка атрибутов + повторная попытка с задержкой
- **Файлы, удаленные без необходимости** — изменен порядок удаления на «сначала файлы» (быстрая обработка ошибок); исправлена блокировка изображений в WPF при предварительном просмотре файлов с помощью параметра `CacheOption=OnLoad`
### Целостность данных
- **Пробелы в конце имени файла** — функция `LoadFamily` больше не выдает ошибку при работе с такими именами файлов, как `"filter .rfa"` (#54)
- **Фантомные типы семейств** — из дерева удалены пустые имена типов, если в семействе нет явных типов
- **Устаревшие данные о параметрах** — функция `UpdateFamily` теперь извлекает и типы, и параметры за один проход
### Пользовательский интерфейс
- **Контекстное меню** — перенесено из элемента шаблона в `TreeViewItem`, теперь работает со всей строкой (#57)
- **Команда «Разместить тип»** — недоступна до тех пор, пока семейство не будет загружено с помощью `LoadToProject`
- **Сообщения о статусе импорта** — строка состояния, понятная человеку, вместо технического формата
- **Разрешения на перетаскивание** — защита `CanEdit` для `CanStartDrag` и `CanDropFamily` (#57)

## Новые функции
- **Обнаружение обновлений на основе VersionGuid** — перечисление `FamilyLoadStatus` (`Загружено`/`Обновлено`/`Текущее`/`Не удалось`); перезагрузка не выполняется, если семейство является текущим
- **Полное извлечение параметров** — извлекает ВСЕ параметры при импорте; сохраняет с допустимым значением `attribute_id`; отображает только параметры, связанные с категорией
- **Подтверждение закрытия корпоративного диалогового окна** — `ISaveableViewModel` + `DialogCloseHelper` с кнопками «Да», «Нет» и «Отмена»; применяется к CategoryTreeEditor, AttributeLibrary, FamilyProperties
- **PathToBitmapImageConverter** — предотвращает блокировку файла в аватаре FamilyProperties
---
## Рефакторинг
- **Унифицированная экстракция** — удалены `IFamilyTypeExtractor` / `RevitFamilyTypeExtractor`; вся экстракция осуществляется через `IFamilyDataExtractionService` + `IFamilyDataImportService`
- **Удален неиспользуемый код** — `IFamilyLoadOptionsFactory`, `RevitFamilyLoadOptionsFactory`, команда `ExtractTypes`, автоматическое сохранение при загрузке/размещении
- **Лучшие практики асинхронного программирования** — `ConfigureAwait(false)` в сервисах, `Task.Run().GetAwaiter().GetResult()` в обработчиках ExternalEvent
- **Типы записей** — удалено использование `record` в циклах, чтобы избежать скрытых выделений памяти.
