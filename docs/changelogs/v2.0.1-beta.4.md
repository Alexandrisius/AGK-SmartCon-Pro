## 🔥 Главное в этом релизе
Ключевая тема релиза — **умное поглощение смещений в PipeConnect**: при соединении элементов сеть больше не «уезжает» целиком. Трубы и гибкие трубы теперь сами поглощают смещение за счёт длины, а multi-DN семейства превращаются в переходные фитинги вместо равномерного изменения всех размеров. Плюс исправления batch-импорта в FamilyManager и расширенная диагностика загрузки плагина.
**Топ-5 изменений для пользователя:**
1. **Сеть больше не сдвигается** — прямые трубы поглощают смещение изменением длины вместо перемещения всей системы (ADR-052)
2. **Flex-трубы поглощают смещение** — смещается только конец у родителя, форма, нарисованная пользователем, сохраняется
3. **Transition-фитинги** — multi-DN семейства меняют DN только на порту со стороны родителя, независимые порты сохраняют свой размер
4. **Устранено зависание ConnectAllChain** — электрические коннекторы (насосы Grundfos и др.) больше не уводят соединение всей цепи в бесконечный цикл
5. **FamilyManager: исправлены категории и имена при batch-импорте** — «Family not found» после переименования и сброс категории на «Без категории» (Issue #135)

## ✨ Новые возможности
### 🌊 Поглощение смещений длиной трубы (ADR-052)
При соединении прямых труб элемент больше не перемещается как жёсткое тело:
- Ближний конец трубы следует за смещением, дальний остаётся на месте — труба просто меняет длину
- Укорочение ограничено 100 мм (минимальная длина трубы), удлинение — без ограничений
- Распространение смещения останавливается на первой поглощающей трубе — вся система отопления больше не сдвигается при подключении одной семьи
- Откат возвращает исходную длину точно
### 🐍 Поглощение смещений flex-трубами
- Flex-труба поглощает смещение перемещением только конечной точки у родителя — все промежуточные точки сохраняются дословно
- Снимок `ElementSnapshot.FlexPoints` восстанавливает при откате точную форму, нарисованную пользователем
### ⏭️ Пропуск пустых уровней и ранняя герметизация цепи
- Кнопки +/- глубины цепи автоматически пропускают уровни, где ничего не меняется
- После каждого инкремента проверяется возможность ранней герметизации цепи
### 🔄 DN-компенсация через переходные фитинги
Вместо равномерного изменения всех размеров семейства применяются стратегии по приоритету:
- **TRANSITION** — семейство принимает валидную конфигурацию из lookup-таблицы, где DN меняется только на порту со стороны родителя
- **REDUCER** — вставка переходника из CTC-маппинга, само семейство не трогается
- **RESIZE** — классический каскад, останавливающийся на первом поглощающем элементе
- Независимые порты сохраняют свой DN: тройник DN25×DN25 больше не превращается в DN20×DN20 при подключении DN20
### 🧩 Поглощение смещений для всех коррекций под фитинги
- `MoveOrAbsorb` применяется везде, где динамический элемент сдвигается ради вставки: фитинг, редуктор, композиты, замена фитинга пользователем, изменение размера, предсоединительная валидация
- Труба укорачивается на длину вставляемой цепочки вместо сдвига сети

## 🔧 Улучшения
### Диагностика загрузки плагина
- Лог старта теперь содержит **имя контекста загрузки** (`SmartCon host context`) — видно, активна ли изоляция зависимостей
- Ошибка «Failed to load SmartCon» теперь пишется в `smartcon.log` с полной цепочкой исключений (раньше была только в диалоге)
- Детектор **дубликата манифеста в ProgramData** — предупреждение, если старая версия SmartCon зарегистрирована параллельно в `%ProgramData%\Autodesk\Revit\Addins` (частая причина «не загружается» после обновления)
- Убрано ложное предупреждение DepGuard про `System.Text.Json` из shared-рантайма .NET 8

## 🐛 Исправленные ошибки
### Загрузка плагина
- **Revit 2025: изоляция зависимостей не срабатывала** — NuGet-сборки Nice3point.Revit.Toolkit 2025.1.0+ больше не содержат механизм изоляции (AddinLoadContext удалён автором в пользу нативной изоляции Revit 2026), поэтому при наличии адд-ина со старой `CommunityToolkit.Mvvm` (например, Eneca Auditor 8.2) плагин всё ещё падал с `0x80131621`. Изоляция на Revit 2025 переведена на тот же ILRepack-merge, что и для Revit 2019–2024: конфликтные библиотеки встроены в `SmartCon.Dependencies`, и чужие версии больше не имеют значения
- **Revit 2025: ошибка загрузки теперь пишется в лог** — ранее «Failed to load SmartCon» была только в диалоге
### PipeConnect
- **Зависание ConnectAllChain** — коннекторы без пищевого домена (электрические, например силовой коннектор насоса Grundfos) отфильтровываются; ранее проглоченное исключение «The shape of the connector is not round» не давало цепи продвигаться, а цикл не имел проверки прогресса — Revit зависал
- **Невалидные комбинации DN** — клапан Giacomini R919 получал комбинацию (DN20, DN15), отсутствующую в lookup-таблице семейства, что ломало все формулы `size_lookup`; теперь изменение размера происходит только в валидных табличных комбинациях (закрыты оба обходных пути валидатора)
### FamilyManager
- **«Family not found» после переименования в batch-диалоге** — имя файла в строке обновлялось мгновенно, а managed-путь пересчитывался debounce-задачей; Import сразу после ввода брал устаревший путь, и `.rfa` попадал в проект под старым именем. Переименования теперь per-row, а Import дожидается завершения всех пересчётов
- **Сброс категории на «Без категории»** (#135) — предвыбор категории командой теперь блокируется (переименование новой семьи не сбрасывает её); категория при переименовании берётся из hash-совпадения дубликата, а не из поиска по имени; мультивыборочное применение категории распространяет блокировку
### Сборка
- Задокументированы безобидные предупреждения ILRepack при сборке (ADR-051) — на работу плагина не влияют

## 🧪 Как тестировать beta
### PipeConnect: поглощение смещений
1. Соедините семейство (насос, клапан) с трубой в системе с длинными ветвями
2. Убедитесь, что сеть осталась на месте — изменилась только длина соседней трубы
3. Повторите с flex-трубой — её форма должна сохраниться
4. Подключите элемент с другим DN к multi-DN семейству (например, тройнику) — независимые порты должны сохранить размер
5. Откат (Ctrl+Z / Отмена) — длины и форма должны восстановиться
### PipeConnect: стабильность
1. Запустите ConnectAllChain на сети с насосом Grundfos (или другим семейством с электрическим коннектором) — зависания быть не должно
2. Измените размер клапана с lookup-таблицей (несколько query-колонок) — комбинация DN должна быть из таблицы семейства
### FamilyManager: batch-импорт
1. В batch-диалоге переименуйте новую семью и сразу нажмите Import — в проект она должна попасть под НОВЫМ именем
2. Выберите категорию командой «Импортировать в категорию», переименуйте семью — категория не должна сброситься
3. Примените категорию к нескольким строкам сразу — она должна закрепиться для всех
### Диагностика загрузки
1. Откройте `%APPDATA%\AGK\SmartCon\smartcon.log` после запуска Revit — должна быть строка `SmartCon host context`
2. Если плагин не загрузился — пришлите этот лог: теперь в нём есть полная причина
### Общее
1. Пришлите `smartcon.log` после теста (путь: `%APPDATA%\AGK\SmartCon\smartcon.log`)
