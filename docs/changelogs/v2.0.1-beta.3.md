# SmartCon v2.0.1-beta.3
**Дата релиза:** 17 июля 2026  
**Предыдущий релиз:** 2.0.1-beta.2 (15 июля 2026)  
**Платформы:** Revit 2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026  
**Статус:** Pre-release (beta) — предназначена для тестирования
---
## 🔥 Главное в этом релизе
Этот beta-релиз содержит два крупных направления: стабилизация **FamilyManager** после введения проектных баз и системная **изоляция зависимостей** плагина от других Revit add-ins.
**Топ-5 изменений для пользователя:**
1. **Изоляция зависимостей** — устраняет конфликты загрузки сборок с другими плагинами в Revit 2020–2022 и Revit 2025+
2. **Content hash v2** — переименованные `.rfa` теперь распознаются как дубликаты по содержимому, а не по имени
3. **Миграции базы FamilyManager** — автоматический переход с hash v1 на v2 с прогрессом и read-only режимом
4. **Modeless batch import** — диалог импорта остаётся открытым с live-прогрессом, паузой и сводкой
5. **Crop аватара** — диалог кадрирования аватара семейства с производным `avatar.png`

## ✨ Новые возможности
### 🏷️ Crop-диалог аватара семейства
FamilyManager получил диалог кадрирования аватара:
- Открывается из «Сделать основным», «Сменить аватар» и при первой загрузке изображения
- Свободное соотношение сторон, зум колёсиком, паноражирование, overlay с затемнением
- Живой превью выделения через `CroppedBitmap`
- Производный `avatar.png` (560×420) — исходные изображения не изменяются
- Единая цепочка разрешения `avatar.png → основное изображение` для свойств и тултипа
- ADR-047, локализация RU/EN
### 🔒 Изоляция зависимостей плагина
Реализована защита от конфликтов версий сборок с другими add-ins:
- **net48 (Revit 2019–2024):** ILRepack объединяет 6 конфликтных пакетов (`CommunityToolkit.Mvvm`, `Microsoft.Extensions.DependencyInjection`, `System.Text.Json`, `System.Text.Encodings.Web`, `Microsoft.Bcl.AsyncInterfaces`, `UTF.Unknown`) в одну strong-named сборку `SmartCon.Dependencies`
- **net8 (Revit 2025+):** `Nice3point.Revit.Toolkit` встроен в `SmartCon.Dependencies`, команды маршрутизируются через изолированный `AssemblyLoadContext`
- `AssemblyResolve` гарантирует загрузку точных версий из папки плагина
- Самовосстанавливающийся `.addin`, updater с бэкапами, установщик с очисткой устаревших DLL
- ADR-051, обновлены dependency-rule, solution-structure, tech-stack
### 📊 Modeless batch import с live-прогрессом
Диалог пакетного импорта больше не закрывается при старте:
- Построчный прогресс-бар со статусами (running/success/error)
- Stop → Resume/Close, крестик в окне запрашивает остановку
- Сводка по завершении
- `IFamilyBatchImportExecutor` с разделением на file/project сценарии
- ADR-048
### 🧬 Content hash v2 + hash-first dedup
- Имя файла исключено из канонической строки хэша — переименованные `.rfa` дают одинаковый хэш
- Dedup сначала проверяет хэш по всем версиям всех элементов, потом имя
- Cross-name дубликат помечается предупреждением и привязывается к существующему элементу через `forcedCatalogItemId`
- `SetActiveVersion` теперь синхронизирует имя элемента с именем файла активной версии
- ADR-049
### 🗄️ Framework миграций базы FamilyManager
- `IDatabaseMigration` + `DatabaseMigrationCoordinator` агрегируют все каталоговые миграции
- Первая миграция: пересчёт hash v1 → v2 с modeless progress, chunk-коммитами, докачкой
- Сервис `IDatabaseUpdateStateService` — единый источник состояния pending-обновления
- ADR-050

## 🔧 Улучшения
### FamilyManager: read-only режим при pending миграциях
- Все команды записи (импорт, загрузка в проект, удаление, drag-and-drop, редактор категорий, сохранение свойств, управление версиями, операции с ассетами) блокируются до обновления базы
- Показывается диалог с пояснением и кнопкой «Обновить сейчас»
- View-only функции (дерево, поиск, свойства, 3D, EditFamily) остаются доступны
- Жёлтый баннер под строкой базы — единый primary-индикатор; красная точка только внутри кнопки инструментов базы
### FamilyManager: UX pending-обновлений
- Единый primary-индикатор — жёлтый баннер с кнопкой Update
- Красная точка убрана из угла кнопки, оставлена только внутри меню инструментов базы
- Drag-and-drop placement теперь gated на старте для loadable-семейств
### Сборка и деплой
- Проект `SmartCon.Dependencies` + ILRepack для net48
- Манифест с isolation tag только для Revit 2026+
- `build-and-deploy.bat` и `release.ps1` адаптированы под новую схему сборки
- Удаление устаревших DLL при установке

## 🐛 Исправленные ошибки
### FamilyManager
- **Подключение legacy-баз** — миграции V15/V17/V18 теперь корректно чистят orphan-строки по всем FK-колонкам и отключают `foreign_keys` на время rebuild, исправляя `FOREIGN KEY constraint failed` (#132)
- **Missing-file строки** — файлы, отсутствующие на диске, больше не блокируют баннер обновления (помечаются `-2` / `RecalculationMissing`)
- **Purge** — теперь best-effort: строки БД удаляются всегда, а недоступные директории считаются и сообщаются для ручной очистки
- **Update-кнопка застревала** — `IsRunning=false` теперь корректно поднимает `StateChanged`, trailing `RefreshAsync` защищён
- **Замедление при подключении БД** — убран лишний `PRAGMA foreign_key_check` при каждом connect/switch
- **Pre-merge validation** — отмена в процессе batch commit больше не выглядит как ошибка чтения файла; purge summary считает реально удалённые версии; `Properties SaveAsync` блокируется в read-only режиме
- **Avatar crop preview** — превью теперь pixel-identical рендереру, рамка inset 10px от краёв viewport, удаление primary-изображения также удаляет derived `avatar.png` (#131)
### Загрузка плагина
- **TypeLoadException / FileLoadException** — устранены краши из-за конфликтующих версий зависимостей, загруженных другими add-ins раньше SmartCon (#134)
- **Revit 2020–2022** — `DisposeAsync`, `ServiceProvider`, `System.Text.Json` теперь разрешаются из изолированной сборки
- **Revit 2025** — устранена ошибка `FileLoadException 0x80131621` (`CommunityToolkit.Mvvm 8.4.0.0`)

## 🧪 Как тестировать beta
### Изоляция зависимостей
1. Установите SmartCon в Revit, где уже есть другой add-in с конфликтующими версиями `CommunityToolkit.Mvvm`, `System.Text.Json` или `Microsoft.Extensions.DependencyInjection`
2. Запустите Revit 2020/2021/2022 — плагин должен загрузиться без `TypeLoadException`
3. Запустите Revit 2025 — плагин должен загрузиться без `FileLoadException 0x80131621`
4. Проверьте 3D-просмотр в FamilyManager — не должен падать с `ViewBoxModel3D` из-за конфликта сборок
### FamilyManager: миграции hash v2
1. Откройте существующую базу с hash v1
2. Убедитесь, что появился баннер «Update database»
3. Нажмите Update — должен открыться modeless progress, пересчитать хэши и завершиться сводкой
4. Проверьте, что read-only команды (импорт, сохранение свойств) блокируются до обновления
### FamilyManager: batch import
1. Откройте диалог пакетного импорта
2. Нажмите Import — диалог должен остаться открытым
3. Проверьте прогресс по строкам, кнопку Stop → Resume/Close, финальную сводку
### FamilyManager: crop аватара
1. Откройте свойства семейства без аватара
2. Загрузите изображение — должен открыться crop-диалог
3. Измените рамку, нажмите Apply
4. Убедитесь, что аватар и тултип обновились
5. Удалите primary-изображение — `avatar.png` должен удалиться вместе с ним
### Общее
1. Пришлите `smartcon.log` после теста (путь: `%APPDATA%\AGK\SmartCon\smartcon.log`)
