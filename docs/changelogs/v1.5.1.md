Исправлено:
- Share Project — некорректное определение расширения файла при работе через файловое хранилище. При использовании worksharing локальный файл содержит суффикс пользователя (например Проект1_a.matorin.rvt). Revit API Document.Title возвращает имя без .rvt (Проект1_a.matorin), из-за чего система именования воспринимала .matorin как расширение файла. Это приводило к неверному парсингу полей и появлению суффикса пользователя в конечном имени shared-файла. Теперь используется полное имя файла с расширением, что корректно разделяет реальные расширения (rvt) и точки в имени проекта. (#18)
