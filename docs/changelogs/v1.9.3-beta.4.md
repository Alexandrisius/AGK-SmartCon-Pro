Похоже, что текст был некорректно отображён из-за форматирования Markdown. Чтобы исправить это, можно убрать лишние пустые строки и изменить структуру заголовков, если это необходимо. Вот пример более компактного и читаемого варианта:

Bug Fixes

* Команда «Разместить тип» теперь недоступна для незагруженных семейств Раньше команда «Разместить тип» в контекстном меню типоразмера оставалась активной даже если семейство не было загружено в проект, и при клике просто ничего не происходило. Теперь:
  * Добавлено свойство CanPlaceType с динамической проверкой IsFamilyLoaded родительского семейства.
  * Команда автоматически блокируется (серая) при выборе типоразмера незагруженного семейства.
  * Защитная проверка внутри Execute предотвращает race condition.
  * После «Загрузить в проект» команда автоматически становится доступной.
* ContextMenu теперь работает по всей строке дерева Исправлено привязку ContextMenu к элементам шаблона (StackPanel/Grid внутри HierarchicalDataTemplate). Теперь:
  * ContextMenu назначается через TreeViewItem Style (FamilyTreeItemStyleSelector).
  * HorizontalContentAlignment=Stretch растягивает содержимое на всю ширину строки.
  * ПКМ работает по любой части строки дерева, включая область справа от текста.

Features

* Enterprise dialog close confirmation pattern Введён паттерн подтверждения закрытия диалогов при несохранённых изменениях:
  * Новый интерфейс ISaveableViewModel для диалогов с отслеживанием изменений.
  * DialogCloseHelper с локализованными кнопками Да/Нет/Отмена.
  * Поддержка отложенных асинхронных действий (AsyncDeferredAction) при подтверждении.
  * Защита _forceClose в DialogWindowBase от рекурсивных вызовов.
  * Применение к: редактору дерева категорий, библиотеке атрибутов, свойствам семейства.
